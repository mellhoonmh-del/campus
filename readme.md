# 🎓 대학생 캠퍼스 라이프 설문 데이터 분석기

Streamlit 기반의 대학생 설문 데이터 시각화 및 키워드/감성 분석 애플리케이션입니다.  
학과별 생활 습관, 공부/수면시간과 학교생활 만족도의 관계, 그리고 학생들이 작성한 한 줄 의견의 텍스트 분석(워드클라우드 및 긍정/부정 감성 분석)을 수행합니다.

---

## 📌 주요 기능

1. **데이터 업로드 및 이상치 자동 정제**
   - CSV 파일 업로드 지원 (UTF-8, EUC-KR 인코딩 자동 처리)
   - 만족도 범주(1~10점) 및 음수 시간 데이터 등 잘못된 데이터를 자동으로 감지하여 분리 및 정제 건수 출력

2. **학과별 필터링 및 요약 지표**
   - 업로드된 파일 내 학과 데이터를 자동으로 인식하여 선택 드롭다운 생성
   - 선택 학과별 학생 수, 평균 만족도, 평균 공부시간 지표 제공

3. **3종 핵심 분석 시각화**
   - **막대그래프**: 학과별 학생들의 생활 습관(통학시간, 공부시간, 수면시간) 비교
   - **산점도**: 일일 공부시간 및 수면시간과 학교생활 만족도 간의 관계 (학년별 구별 및 추세선 제공)
   - **워드클라우드**: 학과별 한 줄 의견에서 자주 사용된 핵심 키워드 구름

4. **[신규] 학과별 한 줄 의견 상세 텍스트 & 감성 분석**
   - **단어 순위 표**: 선택 학과의 한 줄 의견에서 사용된 단어의 전체 순위 및 빈도수 표기 (1위~끝)
   - **Top 10 막대그래프**: 가장 많이 등장한 상위 10개 키워드 시각화
   - **긍정/부정 감성 분석**: 사용된 긍정 단어와 부정 단어의 등장 횟수를 자동 카운트하여 표시 (ex. 사용된 긍정 단어: 33개, 사용된 부정 단어: 21개)

## 📁 프로젝트 파일 구조

```text
├── app.py              # Streamlit 메인 파이썬 실행 코드
├── requirements.txt    # 의존성 라이브러리 목록
└── README.md           # 프로젝트 설명서
```

---

## 🚀 실행 방법

### 1. 필수가요 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 2. Streamlit 앱 실행
```bash
streamlit run app.py
```
```

---

### 📌 깃허브 업로드 최종 안내
현재까지 완성된 **3개 파일**(`app.py`, `requirements.txt`, `README.md`)을 깃허브 저장소에 올리시면 완벽합니다!
